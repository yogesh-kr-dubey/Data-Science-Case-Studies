# Data-Science-Case-Studies

This repository serves as a professional portfolio of my work in data analysis, statistical modeling, and predictive insights. Each project is selected to demonstrate a specific analytical competency, ranging from organizational behavior to global health trends.

## Core Philosophy
I believe that data is only as valuable as the decisions it informs. My approach to data science prioritizes clean documentation, reproducible code, and clear communication of results.

---

## Analytical Projects

### Employee Attrition and Retention Analysis
**Strategic Focus:** Human Resources & Organizational Development
* **Overview:** An investigation into the underlying causes of employee turnover. This project identifies high-risk factors and provides a framework for improving workforce stability.
* **Methodology:** Exploratory Data Analysis (EDA), feature correlation, and data visualization using Python-based libraries.
* **Documentation:** `HR Analytics Employee Attrition.ipynb`

### COVID-19 Time Series Analysis
**Strategic Focus:** Public Health Data & Forecasting
* **Overview:** A major study of pandemic progression through longitudinal data. This project focuses on identifying growth patterns and recovery rates across global datasets.
* **Methodology:** Time-series processing, data normalization, and comparative trend analysis.
* **Documentation:** `COVID19 Time Series Forecasting.ipynb`
